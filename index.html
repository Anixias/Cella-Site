Cella
A minimalistic systems programming language


Cella is a minimalistic systems programming language one level above C. It has raw pointers, no garbage collector, and no runtime. It adds ownership and destructors, borrowed parameters, enums with payloads, generics, traits and modules. The compiler generates code with LLVM for 64-bit Windows and Linux.

The language is still in development and does not yet have a release. The standard library has only just started, so programs call C functions through ext declarations.

Ownership:

Areas owns memory from malloc and frees it in its drop operator when main ends. Calls name how each argument is passed: mut and imm borrow it, no mode takes it by value.

mod shapes

ext
{
	printf: fun(format: cstr, ...) -> i32
	malloc: fun(size: usize) -> ptr[f64]
	free: fun(memory: ptr[f64])
}

Shape: enum
{
	circle(radius: f64)
	rect(width: f64, height: f64)
}

area: fun(shape: Shape) -> f64 => match shape
{
	circle(val r) => 3.14159 * r * r
	rect(val w, val h) => w * h
}

Areas: own rec
{
	data: ptr[f64]
	count: usize

	new: op(count: usize)
	{
		self.data = malloc(count * sizeOf(f64))
		self.count = count
	}

	drop: op
	{
		printf("freeing %zu areas\n", self.count)
		free(self.data)
	}
}

fill: fun(mut areas: Areas, shapes: array[Shape, 3])
{
	for i in 0..areas.count
	{
		areas.data[i] = area(shapes[i])
	}
}

total: fun(imm areas: Areas) -> f64
{
	var sum = 0.0
	for i in 0..areas.count
	{
		sum += areas.data[i]
	}

	ret sum
}

main: fun -> i32
{
	val shapes = [Shape.circle(1.0), Shape.rect(2.0, 3.0), Shape.rect(0.5, 4.0)]
	var areas = Areas(3)
	fill(mut areas, shapes)
	printf("total %.2f\n", total(imm areas))
	ret 0
}
